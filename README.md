# iiuc-bus-management-system
A JavaScript-based university bus management system concept for organizing routes, schedules, student registrations, and seat allocation at IIUC.

# Overview

The project aims to organize university bus routes, schedules, student registrations, seat allocation, and transportation-related announcements.

# Key Features

- Bus and route management
- Stop locations and schedule information
- Student transportation registration
- Route-wise passenger lists
- Seat allocation and capacity tracking
- Schedule change notifications
- Admin dashboard
- Optional live GPS tracking in a future version

# Planned Technology Stack

- Frontend: React or HTML, CSS, JavaScript
- Backend: Node.js / Express or Django
- Database: PostgreSQL or MySQL
- Maps: OpenStreetMap integration (planned)
